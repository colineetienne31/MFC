1. Files for the accuracy study

f.m
Defines the function \(f(x)\) used in the first part of the homework. It provides the analytical function that the numerical methods are applied to.




df.m
Calculates the first derivative \(f'(x)\). It is used both for the exact derivative and in calculations involving the convection equation.




d2f.m
Defines the second derivative \(f''(x)\). This is useful when comparing finite-difference approximations and studying truncation errors.




d3f.m
Defines the third derivative \(f'''(x)\). Higher derivatives help explain the leading error terms of finite-difference formulas.




fd_backward1.m
Implements a first-order backward finite difference for the first derivative:
\[
f'(x_i)\approx\frac{f_i-f_{i-1}}{h}.
\]

Its leading truncation error is generally proportional to \(h\), so it is first-order accurate.




fd_central2.m
Implements the second-order central finite difference:
\[
f'(x_i)\approx\frac{f_{i+1}-f_{i-1}}{2h}.
\]

Its leading truncation error is generally proportional to \(h^2\), making it more accurate than the backward formula for sufficiently small \(h\) on a smooth function.




accuracy_data.m
Organizes the data for the accuracy study: evaluates the function and its derivatives on grids, applies the finite-difference formulas, and calculates numerical errors and observed orders of accuracy for the study script.



2. Files for the convection equation

solve_convection.m
Solves the one-dimensional convection problem numerically. It builds and solves the discrete system using a backward-difference treatment, while applying the prescribed inlet boundary condition.
The output is the numerical solution, which can be compared with the analytical solution to assess the discretization error.




convection_study.m
Runs the convection-equation study across grid resolutions and gathers the results needed to compare numerical and exact solutions, errors, and convergence behavior.



3. Files for the airfoil potential-flow problem

assemble_flow_matrix.m
Builds the discrete finite-volume equations for the potential-flow problem. This is where the main spatial discretization and boundary-condition contributions are assembled.
It selects the treatment of the streamwise and vertical terms, accounts for the airfoil wall through the boundary condition, and constructs the coefficient matrix and right-hand side for the numerical system.
Why it matters: this file determines the mathematical equations the solver actually solves. The transonic and supersonic discretizations in particular should be checked against the exact scheme and boundary-condition requirements in your assignment notes.




solve_flow_fv.m
Coordinates the airfoil-flow calculation. It iterates to update the flow field, recalculates the local coefficient for the governing equation where needed, and checks convergence.
It also derives quantities such as velocity, local Mach number, and density from the potential solution.




solve_sparse_system.m
Solves the linear algebra system generated by the matrix assembly. Depending on the chosen setting, it uses MATLAB's direct solver (backslash) or an iterative method such as GMRES or BiCGSTAB.
Keeping this separate makes it easy to change the linear solver without rewriting the flow discretization.




plot_airfoil.m
Draws the airfoil geometry on the computational-domain plots. This helps you see the wall location relative to the rectangular mesh and the computed flow field.




regime_name.m
Converts a Mach number or flow-regime identifier into a readable label, such as subsonic, transonic, or supersonic. It is mainly a utility for titles, labels, and summary tables.
